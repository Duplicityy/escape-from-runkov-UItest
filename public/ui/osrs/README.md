# Original OSRS interface sprites

These PNGs are unmodified native 1× frames from the OSRS cache dated 2026-11-03, exported through OpenRS2 and published in [this sprite bundle](https://github.com/skeldoor/osrs-sprites/releases/tag/sprites-2026-11-03). `sources.json` records each source frame and SHA-256 digest. The art belongs to Jagex Ltd.

The Loot tracker uses the original collection-log sprite; coins use the original bank map icon. Other files are the corresponding OSRS tabs, minimap status symbols and compass. No icons are drawn with SVG or CSS.
